Have you ever went to a website and it just takes a while to load? You see a blank screen with a loading icon, and you keep refreshing and refreshing it. Or maybe you finally enter a website but you see an image that takes a while to load.

These are the little things that decide if a user wants to stay on the website or leave and never look back.

Applying this in my experience

Around October 2025, I worked on a website with 8 other devs to showcase/promote a tech event, and I was assigned to work on a job board component. After submitting a PR, a senior-ish dev gave me feedback and talked about the nitty gritty things.

This is where I first learned about making website performance optimal and accessible. He told me to reduce the pixel dimensions of the image icons I implemented since it was unnecessary having logos being too large if they're meant to become smaller. He also told me to use a tool called ImageOptim to reduce the space. I also was told to add aria labels to important assets in case it would have a hard time to load, and users would need to know what was supposed to be there.

Fast forward to this summer 2026, I'm co-leading a team of devs to build the website for our campus's hackathon, and applying best practices and methods to make the website load faster and have optimal performance (something I decided to do myself).

Takeaways and what methods I used

Reduce image sizes to what you need it to be

Having images with high quality and large pixel dimensions (e.g. 1920x1080 px) will have a longer time loading. What I do first is use the image and implement it in a website, adjusting the size to what it needs to be with the HTML properties. Then I inspect the dimensions of that image via dev tools. Finally I take the actual image and use my computer's image editor to adjust the pixel's dimensions of that image.

Optimize image space

The more storage your website holds, the longer it struggles to compile and load. After I do step 1, I realized that once I shrink the size of the image, I'll have lots of storage to free up from the image. The tool I use is called ImageOptim. You drag images and it automatically reduces the images' space. This is a convenient way to optimize your website's performance if you follow step 1 and this step, which I do first.

Delete unused files and assets

Keeping and hoarding unused files and images can take a lot of space on your webapp, which can slow down performance. It's self explanatory to just delete them if there's no point using them. This will remove baggage from your webapp and possibly speed up your webiste to an extent.

Uninstall unused dependencies

I find this helpful but if you open a website, it bundles and compiles dependencies using various Javascript files to help the website run and function. From my intuition, dependencies are written in some form of programming language, and that is exported so we can download and import it for us to use into our code. Dependencies takes plenty of space and you would need files to access those dependencies. So deleting unused dependencies frees up space ensures that the bundler won't need to access them anymore and get useless storage.

Take some of it with a grain of salt since idk well about javascript bundling and dependencies and what role they play on a website

Observability

I use Chrome's dev tools to inspect how my website's doing. I use right click > Inspect > Performance to check metrics. I also see how fast each of the assets load by doing right click > Inspect > Network. Additionally, I check the Performance, Accessibility, Best Practices, and SEO by doing right click > Inspect > Lighthouse. I'm using the chrome dev tools but additionally I try using Chrome Web Vitals extension. Keep in mind the extension is deprecated (The Web Vitals extension, now in DevTools) so also take it with a grain of salt
